# 游戏店铺自动批量购买工具

一个基于 Python + Tkinter 的游戏店铺自动批量购买工具，支持自动遍历商品列表、拉满购买数量、OCR识别总价、金额超阈值确认等功能。

## 功能特性

- 🛒 **自动批量购买**：自动遍历商品网格，依次完成购买
- 🔢 **数量拉满**：自动点击 + 号拉满购买数量
- 💰 **OCR总价识别**：自动识别购买总价
- ⚠️ **金额阈值提醒**：总价超过阈值时弹窗确认，支持"全是/全否"批量批准
- 📊 **实时计数器**：显示已点击商品种类、+号次数等
- 🔒 **货币不足检测**：自动检测货币数量，不足时停止
- ⌨️ **快捷键支持**：F9 开始/暂停，F10 停止，Ctrl+T 置顶
- 💾 **配置保存**：校准后可保存配置，下次直接加载
- 🪟 **窗口置顶**：支持窗口始终置顶

## 快速开始

### 环境要求
- Windows 10/11
- Python 3.10+
- Windows 自带 OCR（winocr）

### 安装依赖
```bash
pip install pyautogui mss Pillow numpy opencv-python keyboard winocr
```

### 运行
```bash
python shop_buyer.py
```

或双击 `start.bat` 启动。

## 使用方法

1. **校准坐标**：点击「校准坐标」，按 9 步提示完成所有坐标校准
2. **设置参数**：设置金额阈值、列数、行数、点+号次数
3. **开始运行**：按 F9 或点击「开始运行」

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| F9 | 开始 / 暂停 / 继续 |
| F10 | 停止本次运行 |
| Ctrl+T | 切换窗口置顶 |
